⚠ 변경 전 확인하세요

선택한 Photoshop 버전의 모든 외부 JSX 실행 정책에 영향을 줍니다. 신뢰할 수 있는 스크립트만 실행하세요.

변경하려면 Photoshop을 종료해야 합니다. 기존 설정은 백업되며 Photoshop을 다시 실행한 후 적용됩니다.

스크립트 경고 설정 검토

선택 사항입니다. 경고 유지가 권장 기본값이며, 변경하지 않아도 프로그램을 사용할 수 있습니다.

가이드 전체 흐름

1. 사용할 Photoshop 확인
선택 버전, 실행 파일 경로, 실행 상태를 확인. 확인만 할 때는 종료 불필요.
2. 스크립트 실행 경고
선택 사항. 명시적 동의, 종료 확인, 백업, 재시작 및 영향 범위 안내.
3. Aseprite 권한
스크립트 설치 → File > Scripts에서 실제 Trust 승인 → 테스트 문서 F4/F5 확인.
4. 마무리
설치, 키 등록, Trust, 실제 동작 확인을 별도로 표시. 미확인을 완료로 바꾸지 않음.

Codex 구현 참고 사항

  • 기존 PySide6 UI와 c4f628a 이후 실제 소스를 먼저 확인. 이 HTML의 스타일을 그대로 도입하거나 웹 기술로 이전할 필요 없음.
  • 공식 표시명 Photoshop ↔ Aseprite. 내부 ps2ase, bridge_ui.exe, 설정 경로 및 외부 호스트 계약 유지. 운영 카탈로그 변경 금지.
  • 전송 흐름의 그룹화와 버튼 위계, 미리보기 공간의 효율, 진단 기본 접기를 우선 검토. 실제 제공되는 기능·상태·조작 위치에 맞게 조정하고 임의 기능 추가 금지.
  • Photoshop 종료/버전 선택, 스크립트 경고 변경의 명시적 동의와 백업, Aseprite Trust 상태의 정확성을 유지. 실제 검증하지 않은 상태를 성공으로 표시하지 않음.
  • 기존 테마와 언어를 보존. 좁은 창, 한국어·영어·일본어 및 DPI 변화에서 겹침/잘림/접근 불가 방지. 필요하면 스크롤 등 레이아웃 정책 적용.
  • 시안은 docs/design-references/, 실제 구현 검토 자료는 docs/ui-reviews/에 구분 보관. 실제 구현 증거와 커밋 고정 링크를 보고. Windows Use는 필요한 실제 확인에만 사용.
  • 운영 버전 0.3.6 및 검증된 0.3.7-rc1 후보를 보존. 새 운영 배포 후보는 별도 요청 시에만 제작.
