## 구현 기준
1. 기본 메인 창의 **미리보기 표시 영역 높이**를 같은 화면·DPI·업데이트 배너 조건에서 ad02750 대비 약 1.5배 확보한다. 기본 높이를 필요한 만큼 늘리고 작은 화면에서는 화면 범위 내에서 축소한다. 버튼/편집 영역 확대가 목적이 아니다. 최근접 보간과 원본 보호 유지. 창 크기 기억 기능이 있다면 기존 사용자 선택 보존.
2. 첫 실행 소개와 실제 초기 설정을 분리한다. 자동 탐색/설치 파일·단축키 상태를 읽기 전용으로 확인해 필요한 설정을 알려주고, 사용자가 시작하거나 바로 작업할 수 있도록 한다. 신규 사용자 또는 소개 미확인 사용자 대상. 기존 숨기기 선택을 되살리거나 Trust 미확인을 이유로 매 실행마다 강제 표시하지 않는다. 기존 사용자에게 업데이트 필요 안내는 유지한다. 나중에 설정에서 언제든 가이드를 열 수 있다. 소개 SVG의 레이어→프레임 예시는 해당 모드를 명시하며 일반 복사 동작과 혼동하지 않는다. 실제 예제 캐릭터와 레이어별 시각 자료를 사용한다.
3. 소개 다음 실제 가이드는 연결부터 시작한다. 단계 수·이전/다음 의미 정합성 유지. 연결 페이지에 현재 확인하는 이유, 선택 버전이 맞으면 계속/다르면 변경, 다음 단계 안내를 표시한다. 호스트 미설치/경로 무효 때는 해결 행동을 별도 표시한다. 각 단계에서 선택과 다음 행동이 자연스럽게 연결되도록 하되 범위 밖 전면 개편은 하지 않는다.
4. 현재 F5 지연 안내는 start_probe() 호출 때부터 12초를 센다. 준비·읽기·승인 중에 실패 안내로 바뀌지 않도록 시간 기준의 자동 전환을 제거하는 방향을 우선한다. '도움이 필요하신가요?' 또는 '결과가 오지 않나요?' 같은 보조 행동으로 필요 시 해결 절차와 새 파일 준비를 열고 실제 오류는 즉시 표시한다. 결과 수신 감시는 계속하며 준비 완료 버튼을 다시 만들지 않는다. F4에도 같은 원칙을 적용하되 자동 결과 및 직접 확인 경로는 보존한다. 화면을 읽는 도중 레이아웃이 바뀌거나 스크롤이 점프하지 않도록 한다.
5. AsepriteSetupDialog의 텍스트뿐인 도움말에 **실제 시각 자료**를 삽입한다. File > Scripts > aseprite_copy / aseprite_paste 선택 위치, 실제 파일 접근 승인창 및 허용 위치를 실제 설치된 호스트에서 캡처하고 필요한 부분만 강조한다. SVG의 메뉴는 개념도이며 권한 창 영역은 의도적으로 실제 캡처 삽입 자리로 남겼다. 실제 승인창을 확보하지 못하면 명확하게 개념도라고 표시하고 검증된 메뉴/조작 그림을 먼저 제공하며 미검증을 보고한다. 가짜 호스트 캡처로 대체하지 않는다. 작업 중인 문서/개인 경로 공개 금지. 기존 Trust 기록 초기화 금지. 도움말에 현재 F5/F4 연습에 필요한 문서와 단계만 명시하고 닫으면 연습이 유지된다.
6. 기존 PySide6, Southpaw 테마, 한·영·일 번역, 연습 세션/데이터 격리, F5 결과 감시, 오류 복구, 설치 동의 및 백업을 유지한다. 새 빌드와 배포는 보류한다. 구현 후 대표 화면으로 시안과 비교하고 실제 확인 범위를 구분한다.

원본 사용자 화면은 공개 저장소에 포함하지 않는다. 제품 코드 및 배포 설정은 이 시안 등록으로 변경하지 않는다.
