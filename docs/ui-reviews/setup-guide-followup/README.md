# 초기 설정 가이드 후속 검토

2026-11-25 · Photoshop ↔ Aseprite 0.3.7 개발 소스. 기존 0.3.7-rc1 패키지와 운영 0.3.6은 그대로입니다.

사용자 제공 Aseprite 설정 시안을 참고해 설치·Trust 카드와 단축키 테스트 카드를 구분했습니다. 아래 이미지는 구현된 Widgets를 Windows Qt에서 실행해 `QWidget.grab()`으로 촬영한 **합성 상태**입니다. Photoshop·Aseprite 경로, 상태, F5 결과, F4 사용자 응답은 테스트 도구가 제공했습니다. 네이티브 제목 표시줄은 Qt 클라이언트 캡처 범위 밖입니다.

| 확인 상태와 미검증 표시, 단계 이동 | [마무리 점검표 · 100%](review.png) |

- 100% 논리 창 520×590, 200% 논리 창 335×440에서 위 대표 화면을 확인했습니다. 캡처한 화면은 가로·세로 스크롤 여유값이 0이었습니다. 더 작은 창은 본문 스크롤을 사용합니다.
- 가이드 자동 테스트 22개 통과. 별도 시작 순서 테스트는 이전 `7993a75`에서도 재현되는 Windows 접근 위반으로 이번 실행 결과를 확보하지 못했습니다.
- F5는 결과 파일의 이름·작업·완료 계약이 일치하는지 관찰합니다. 물리 키 입력과 실제 호스트 Trust는 이번 작업에서 재검증하지 않았습니다. F4는 직접 확인을 기록하며 자동 검증으로 표시하지 않습니다.
