# 초기 설정 종료: Windows 잠금 재검증

[허브 이슈 #2](https://github.com/rodetoast/southpaw-development-hub/issues/2)의 cb53201 재현에서는 실습 폴더 삭제의 WinError 32/5에 이어 RecursionError가 발생해 가이드 종료와 Qt finished 신호가 막혔습니다.

수정본은 실습 세션을 무효화한 뒤 창을 닫고, 실제 폴더 정리는 별도로 시도합니다. 잠긴 항목은 강제 삭제하지 않으며 GUIDE_CLEANUP_DEFERRED 진단을 남깁니다. 폴더나 JSON이 남아 있어도 종료된 실습 탭은 일반 클립보드로 전환되지 않습니다.

## 개발 PC 결과

- Qt offscreen 자동 테스트 157개 통과. 공유 위반과 재귀 예외를 주입해 창이 닫히고 finished가 한 번만 발생하며 설정이 저장되는지 확인했습니다.
- 현재 실습용 Photoshop 워커가 있으면 디스크 삭제를 워커 종료까지 미루며, 성공 표시와 물리 F5 확인은 구분됩니다. 종료 표식이 있는 경우 남아 있는 실습 JSON의 F5/F4 접근을 Lua 회귀 검사로 차단했습니다.
- 실제 GUI 및 Windows 삭제 잠금 재현은 이번 개발 PC 검증에 포함되지 않았습니다.

## 별도 테스트 PC

1. 이 수정본의 Python 소스로 실행합니다. 실습 탭 보호까지 확인하려면 시험용 Aseprite 프로필에서 동의 후 수정본의 두 Lua 스크립트를 적용합니다. 기존 업무 문서나 설정은 사용하지 않습니다.
2. 새 실습 세션을 만들고 이슈 #2와 동일하게 실습 하위 경로를 FILE_SHARE_DELETE 없이 유지합니다. 잠금을 잡은 채 4/4에서 완료를 클릭합니다.
3. 클릭 한 번에 가이드가 닫히고, finished가 한 번만 발생하며, 메인 창 사용과 설정 저장이 정상인지 확인합니다. GUIDE_CLEANUP_DEFERRED 로그, 잠금이 유지되는 동안 파일이 남는지도 확인합니다.
4. 종료된 실습 탭의 F5/F4가 일반 클립보드를 수정하거나 붙여넣지 않는지 확인합니다. 취소/닫기는 새 실습 세션으로 별도 확인합니다. 일반 작업물에 대한 전송 전체 시험은 반복하지 않습니다.
5. 잠금을 해제하고 시험용 데이터만 정리합니다. 이슈 #2에 사용한 커밋, Windows/Aseprite 버전, 결과와 로그를 첨부합니다.

## 유니코드 경로 후속 검증

[독립 검증 보고](https://github.com/rodetoast/southpaw-development-hub/issues/2#issuecomment-7215015926)에서 가이드 종료·정리 보류·F5 보호·취소는 통과했지만, 한글 경로의 종료된 F4 실습 탭이 잠금으로 남은 JSON을 읽고 수정되는 것을 확인했습니다. 파일 접근 경로와 비교 키를 분리하고 비교에서는 ASCII 대문자만 변환합니다. 표식을 조회하지 못하면 실습을 거부합니다.

Windows의 Aseprite 배치에서 ASCII, 한글, 일본어, 한글·일본어·공백 혼합 경로마다 활성 F4/F5, 종료된 F4/F5, F4의 트랜잭션 직전 종료 및 표식 조회 예외를 확인했습니다. F4 잠금 사례는 Windows 삭제 공유 없이 JSON을 열고 실제 삭제 거부를 확인하고 실행했습니다. 거부 시 클립보드를 읽지 않고 문서 픽셀·cel·레이어·프레임 및 완료 표식을 변경하지 않는지 검사했습니다.

[독립 Windows 최종 결과](https://github.com/rodetoast/southpaw-development-hub/issues/2#issuecomment-7216568479): 두 Lua 파일의 해시를 확인한 뒤 Windows 자동 F4 입력으로 종료된 혼합 경로 탭의 문서·클립보드 보호와 활성 실습 붙여넣기를 확인하여 이슈 #2를 닫았습니다. 물리 키 및 설치 패키지는 별도 범위입니다. RC2 패키지 검증은 [런처 인계](../../RELEASE_0.3.7_HANDOFF.md)를 따릅니다.
