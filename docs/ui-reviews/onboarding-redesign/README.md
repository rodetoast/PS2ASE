시안처럼 소개를 가이드 안에 두고, 경고 선택과 실제 승인창 관찰을 분리했습니다. 고정 SVG나 HTML을 화면 전체에 붙이지 않고 실제 접근 가능한 버튼, 스크롤 및 한·영·일 문자열을 사용했습니다. 타임라인과 편집 그림은 사용자가 제공한 예제의 첫 프레임에서 추출한 캐릭터와 실제 셀 구조를 사용합니다. Photoshop 레이어 패널과 Bridge 도식은 조작 위치를 설명하는 그림이며 호스트 캡처가 아닙니다. F4의 수동 확인은 대상 파일을 표시한 뒤 12초 동안 자동 결과가 없을 때만 나타납니다.

## 확인된 원인과 데이터 보호

- 신고된 구 승인용 PNG와 일치하는 `metadata.json`, `trigger_copy.json`, `status_done.json` 11세트를 확인했습니다. 모두 Aseprite 픽셀 레이어 1개와 `done`을 기록했습니다. 이전 코드는 해당 이름을 일반 클립보드에서 제외한 뒤 활성 연습·준비 상태가 일치하지 않아 가이드에도 반영하지 않았습니다. `Hotkey sent`만으로 성공을 판단하지 않았습니다.
- `Stale job state cleared`는 복사 실패 로그가 아닙니다. 이전에는 유효한 Bridge 클립보드를 연속으로 읽지 못했거나 작업 폴더가 없으면 미리보기 및 Undo/Redo 상태를 해제했습니다. 당시 어느 조건이 발생했는지는 기존 로그로 특정할 수 없습니다. 클립보드 접근 실패는 이제 빈 클립보드로 세지 않고, 연습 중에는 기존 작업 폴더가 남아 있는 한 비Bridge 클립보드 때문에 이력을 지우지 않습니다. 실제 새 일반 복사 결과의 갱신은 막지 않습니다.
- 별도 승인용 문서를 제거했습니다. F5는 `Copy practice.aseprite`의 세션 경로·토큰·프레임·작업 파일을 검사하고, F4는 별도의 `Paste practice.png`를 유지합니다. 스크립트 실행과 이전 사용자의 확인 기록은 실제 현재 권한 보유 여부와 다릅니다. 새 파일은 설치 변경이 필요한 경우에만 기존 방식으로 백업·동의를 받아 설치합니다. 숨겨진 가이드 없이도 메인 창에서 업데이트를 확인할 수 있습니다.
- 직접 열 수 있으면 Aseprite에서 해당 파일만 열며, 그렇지 않으면 탐색기에서 파일을 선택합니다. 업무 탭에 F4를 누르면 기존 일반 붙여넣기가 실행된다는 점을 연습 화면에서 안내합니다. 앱은 연습을 위해 업무 탭에 단축키를 보내지 않습니다.

## 검증과 남은 범위

- 실제 Windows Photoshop 2027과 격리된 Aseprite 1.3.18.6 배치를 연결했습니다. Qt 가이드에서 준비 버튼 없이 F5 결과를 받았고, 지정된 Photoshop 연습 문서 복사 → 빈 연습 문서의 실제 cel 생성 → F4 토큰 수신 → 점검표를 확인했습니다. Photoshop 연습 문서만 닫고 기존 활성 문서를 복원했습니다.
- 자동 테스트 141개가 모두 통과했습니다. Aseprite 배치에서 사용자 예제의 프레임 1·3 복사, 빈 프레임 2의 오류 안내 및 일반 결과 폴더 미변경을 확인했습니다. 가이드의 다른 경로·토큰·부분 결과 거부와 기존 편집 이력 보존을 자동 테스트했습니다. Qt 화면은 380 논리 픽셀 폭에서 100% 및 200%로 렌더링했습니다.
- 확인되지 않은 범위: 물리 F5/F4 및 탐색기에서 실제 창 전환, 최초 Trust 승인, Photoshop 실행 경고 변경 뒤 실제 승인창 출현 여부, 패키징된 EXE의 실행. 이번에는 실제 사용자 설정과 설치본을 변경하지 않았습니다.
- 기존 일반 양방향 전송과 좌표·알파 비교는 [이전 실기동 보고서](../setup-practical-check/HOST_VALIDATION.md)를 재사용했습니다. 예제 원본과 미리보기 파생 이미지 경로를 spec에 추가했으나 새 EXE·ZIP 빌드와 배포는 하지 않았습니다.
