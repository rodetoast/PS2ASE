- 100% 논리 창 520×590, 200% 논리 창 335×440에서 대표 상태를 확인했습니다. 각 캡처의 가로·세로 스크롤 범위는 0이었습니다.
- 직접 열기는 선택된 Aseprite가 종료된 것으로 확인된 경우에만 실행 파일에 생성한 PNG 하나를 인수로 전달합니다. 실행 중이거나 상태가 불명확하면 기존 창에서 파일을 열도록 안내합니다. 실행 요청이 실패해도 폴더 버튼을 사용할 수 있습니다. [Aseprite CLI 파일 인수](https://aseprite.org/docs/cli/) · [Qt 프로세스 실행 계약](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QProcess.html#PySide6.QtCore.QProcess.startDetached)
- 개발 PC에서 Aseprite 실행 중임을 확인했습니다. 작업 문서를 보존하기 위해 프로세스를 종료하거나 새 인스턴스를 띄우지 않았습니다. 종료 상태의 실행 요청·실패 대체 경로는 자동 테스트에서 검증했으며, 실제 PNG 탭 열기·물리 F4/F5·Trust 승인은 재검증하지 않았습니다.
- 시작 순서 테스트의 접근 위반은 창 생성 전에 Qt 버튼의 연결 대상인 `BridgeApp.show_tutorial`을 `Mock`으로 치환했을 때 재현됐습니다. 일반 함수로 대체한 가이드 모의 호출과 정상 창 생성은 통과했습니다. 창 생성 후 인스턴스 스파이를 연결해 기존 순서·튜토리얼 미호출 검증을 유지했고 같은 가이드 테스트 24개가 모두 통과했습니다. 제품 시작 코드는 변경하지 않았습니다.
- 기존 0.3.7-rc1과 운영 0.3.6을 유지합니다. 새 배포 ZIP 및 운영 카탈로그는 변경하지 않았습니다.
