# 연습용 원본

사용자가 직접 제작하고 공개 저장소 등록 및 프로그램 연습용 사용을 승인한 원본입니다. 2026-11-26 등록. 300×300 RGBA, 4개 레이어, 3개 프레임(2번 빈 프레임). 1370 bytes. SHA-256: `e5a2c2ad4d231770f4d4c8b24b7fb847b81ce33e97ccce58ceec59ad31570d0d`.

F5는 1 또는 3번 프레임의 픽셀이 있는 셀을 선택해 연습합니다. 2번 프레임은 빈 셀 안내 검증에 활용할 수 있습니다. F4는 별도의 빈 대상 문서로 진행합니다. 원본을 직접 수정하지 않고 세션별 복사본을 사용합니다. 기존 PNG 전용 식별 규칙을 안전하게 확장하고 일반 클립보드·이력 격리와 이전 결과 거부를 유지합니다. 사용 방법의 타임라인 캡처 및 예시에도 재사용합니다. 패키징 시 리소스 포함 여부를 확인합니다.

[디자인 및 구현 의도](../../docs/design-references/onboarding-redesign/README.md). 이 등록은 원본 제공이며 제품 코드 연결이나 빌드 검증 완료를 의미하지 않습니다.

`character.png`는 Aseprite 1.3.18.6에서 원본 프레임 1을 합성한 뒤 투명 여백만 자른 파생 이미지입니다. 가이드와 사용 방법의 확대 예시에 사용합니다. 원본은 세션별 복사본으로 사용하며 변경하지 않습니다.
